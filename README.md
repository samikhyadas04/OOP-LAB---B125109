# Lab 1 – Structures in C (Revision)

This repository contains solutions to basic **Structure** programs in C as part of the Object-Oriented Programming Laboratory.

| Question | Program | Description |
| :--- | :--- | :--- |
| 1 | Student Details | Create a `Student` structure, accept details, and display them. |
| 2 | Employee Record | Store details of 3 employees using a structure and display all records. |
| 3 | Book Information | Create a `Book` structure and display book details. |
| 4 | Product Details | Calculate the total cost of a product using price and quantity. |
| 5 | Rectangle | Find the area and perimeter of a rectangle using a structure. |
| 6 | Distance | Add two distances represented in feet and inches. |
| 7 | Student Marks | Calculate the total and average marks of a student. |
| 8 | Largest Salary | Find and display the employee with the highest salary. |
| 9 | Array of Structures | Display students whose CGPA is greater than or equal to 8.0. |
| 10 | Nested Structure | Use nested structures to store student details along with date of birth. |

## Concepts Covered

`Structures` `Arrays of Structures` `Nested Structures` `User Input/Output` `Basic Calculations`

| Question | Program | Description |
